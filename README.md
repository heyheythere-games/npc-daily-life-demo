# NPC Behavior & Daily Life System: playable demo

Play the demo of **NPC Behavior & Daily Life System**, an Unreal Engine plugin by heyheythere, before you buy it.

## Download

- [Latest release](../../releases/latest): `NPCDemo-Win64.zip`, for Windows 10 or 11, 64-bit.
- Unzip it anywhere and run `NPCDemo.exe`.
- The demo shows the plugin's version 1.0.0, the same one sold on Fab.

## Controls

| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | W A S D | Left stick |
| Look | Mouse | Right stick |
| Jump | Space | A |
| Run | Shift, held | Left stick click, held |
| Score panel, the nearest villager | Tab | View |
| Score panel, the one ahead | E | Y |
| Make a noise | F | B |
| An hour on | T | X |
| Controls card | I | D-pad down |
| Guide | G | D-pad right |
| Save, load | F5, F9 |  |
| Start over | R, twice | Menu, twice |
| Pause | Esc |  |
